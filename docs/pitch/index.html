Veilos

Privacy-native OS for autonomous organizations on Midnight.

Humans define the rules. Agents execute them. Midnight proves they were followed.

Problem

Agents need rules.
Public chains leak them.

  • Spend limits, vendor lists, and credentials on a transparent ledger expose the operating model.
  • Off-chain policy cannot be independently verified.
  • Orgs should not choose between confidentiality and verifiability.

Solution

Private inputs.
Verified actions.
Public results.

Veilos commits private agent policy on Midnight Compact. Witnesses stay off the public ledger. AUTHORIZED is only SucceedEntirely plus the exact indexer action.

The blockchain sees the proof. Not the secret.

Why Midnight

Dual ledger. Not a Solidity stand-in.

  • Compact 0.23 / compiler 0.31.1
  • MidnightJS 4.1.1 · DApp Connector v4 · proof-server 8.1.0
  • Official Preview indexer and RPC
  • Private state encrypted (PBKDF2 + AES-GCM)
  • Proofs stay local — no hosted prover

Product

One operator loop

  • Encrypted operator vault
  • Organization + founding member
  • Private agent policy
  • Authorize payment
  • Privacy Inspector
  • Org-issued credentials
  • Unshielded NIGHT treasury
  • Private ballots
  • Sealed procurement
  • Scoped auditor views
