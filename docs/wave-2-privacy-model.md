# Wave 2 Privacy Model

## Public by design (unshielded settlement)

Amount, recipient address, treasury/contract, transaction id, block time.

## Remains private

Policy limits, accumulated spend, credential body, reason, losing bids, individual ballot choices, auditor claims outside a grant.

## Failed proofs

A rejected authorization or settlement writes no public failure row and does not print the private constraint.

## Auditor disclosure

Encrypted off-chain bundles. Only a disclosure commitment is public. Grants are purpose-bound, scoped, and expiring.
