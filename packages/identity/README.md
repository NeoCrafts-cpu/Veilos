# `@velios/identity`

Stable identity ports for VELIOS.

Production Wave 2 identity is a dApp-specific holder commitment derived from an organization-issued credential secret.

The official Midnight DID adapter stays behind `officialMidnightDidAdapter()`. Installed `@midnight-ntwrk/midnight-did-api` is not a production dependency: published 0.5.0 targets MidnightJS 4.0.2, not the Wave 1 pin 4.1.1.
