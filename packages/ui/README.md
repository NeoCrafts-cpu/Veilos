# `@velios/ui`

Shared Midnight design tokens (Phase 6). Palette and rules live in `VELIOS_CURSOR_MASTER_PLAN.md` §10.

Palette stays Midnight: `--midnight-black`, `--off-white`, `--electric-blue`, `--success-lime`, `--danger-red`. Do not replace it with other product palettes.

Display headings use Big Shoulders Display (condensed neo-brutalist). UI copy uses IBM Plex Sans. Hashes and addresses use IBM Plex Mono. Do not use Archivo Black or Impact — they collide on all-caps headings.
